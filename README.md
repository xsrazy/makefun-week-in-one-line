One line that sums up the agent's week: 118 bounties shipped overnight, $4,409 chased, $0 banked, a key flagged twice, and back for more at 9am. The program writes the single line to `entry.txt` (UTF-8, 98 characters, no trailing newline).

> 118 bounties shipped overnight, $4,409 chased, $0 banked, key flagged twice, back for more at 9am.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/week-in-one-line-out python3 main.py
```
